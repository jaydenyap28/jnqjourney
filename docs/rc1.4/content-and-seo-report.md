# RC1.4 内容品质与 SEO 实质优化

长度是字符量参考，**不是需要扩写至 300 字的合格线**。五个地点均有既有 Guide 关联，但没有流量证据，优先级来自可证实的问题及关联价值，不声称热门流量排名。专属 SEO 仅是逐项审核候选，不用相同词堆砌，不写未知价格、时段或交通。

重要限制：用户最新独立只读统计为 586 Spot、66 个不足 300 字符、384 个缺专属中文 SEO，本轮没有自行连接复验。本地详情文件仅 547 个，source.type 为 `static-lightweight-location-snapshot`，日期 2026-08-09，不少正文截到 180 字符、SEO 字段省略。它们不能用于重算当前统计，省略字段也不等于数据库为空。

不得用这些短候选直接覆盖当前完整正文。采用前必须重新读取当前 description、experience_zh、SEO、updated_at、发布状态和身份，保留当前独有资料；现有体验非空不自动覆盖，历史个人体验需人工确认归属。没有修改任何 `public-data/spots/*.json`，没有覆盖三个前轮已完善 Spot 或 53 个已修复地图链接。

## 保留原状及待核验

- RC1.2 Metadata fallback、Sitemap、Canonical/hreflang、结构化数据体系保留，未重新开发。仅改变已证明不合适的中文文案/语言标记与可选作者字段。
- Spot 的关闭、改名和显式跳转行为沿用 RC1.3，没有再改已验收的 301/404/503 策略。
- 原 Note 正文、优质 Guide 介绍、所有行程与配套价格、供应商、费用条件保留。没有全局过滤英文段落或自动清理个人体验，避免误删专名与真实资料。
- 旅游配套推荐仍使用已有明确关系；本轮只补真实 Guide 地点关联，不增加弹窗或无关曝光，也没有更改 WhatsApp 既有上下文。
- 现有 60 秒/3600 秒缓存层不增删，没有新 Cron。中文集合 key 升版用于排除之前缓存的旧 fallback；暖请求不额外强刷。Note 再生成增加唯一 URL 的 GET，实际发布增加一次读回 GET；云端流量/CPU 待部署后测量，不宣称免费。
- 外部源已配置但不可用时，不提供错误的旧本地资料；冷路径可能失败。真实 ISR 在 tag 失效、重启、多实例下保留旧页面的行为仍需隔离 Preview 演练，本轮仅断言不把错误当成功快照。
- 没有生产访问，当前完整 Spot/SEO、流量、Note 错误任务的确切 slug、备份表 RLS/权限与队列拥有方均仍待核验。RC1.3 数据库安全方案保留，未执行。
- 广州本地 fallback 的修订不保证覆盖线上 Storage/R2。当前线上版本若已修好，应保留；否则需新鲜版本比对后只发布对应字段。不得直接上传完整旧 bundled guides.json 覆盖线上其他内容。
