## 正式写作与发布操作

以下是之后具备部署与内容发布授权时的操作。本轮没有执行这些云端操作。**现有 Note 编辑器在停笔约 3 秒后自动保存到云端；草稿保存也会写入云端，Published 勾选后自动保存会使文章公开。** 不要把生产后台当作纯本地预览。

1. 在 `/admin/notes` 新建 Note，保持 **Published 不勾选**。填写完整 Title、稳定的 Slug、Short Title、Tagline 和短摘要。Title 是 H1 与 SEO 标题来源；站点会附加品牌。Card Summary 是卡片摘要及 SEO Description 首选来源，建议写纯文字、控制在 160 字以内。
2. 在 **Cover Video URL / 选填影片** 粘贴自己的 YouTube URL。普通 watch、youtu.be、Shorts、live 和 embed 链接均支持。影片会出现在文章开头；也可通过“插入影片链接”放在某段之后，并选择 Landscape 或 Portrait。不要把同一影片无意重复插入封面和正文。
3. 正文使用下方骨架。每个标题、段落、图片、视频、表格前后留一个空行；标题不会自动把紧接的正文拆成下一块。`##` 是章节，`###` 是小节或 FAQ 问题。标题从 H2 开始，正文无需额外 H1。
4. 图片用现有上传/关联景点图片入口，写准确 alt 和图注；出发前的示意图标明来源与性质，不能当作日本实拍。表格可点击“插入表格”，FAQ 与参考资料可点击“FAQ 与来源”，替换全部占位文字和 URL。
5. 在 **Related Notes / 延伸阅读** 中选择同系列文章并拖动/调整顺序；每篇需各自配置想展示的延伸阅读。后台能选择草稿，公开页会自动略过尚未发布成员；不需要用虚假链接预占系列位置。
6. Related Spots 只选实际相关的已有地点；需要定位到具体地点时，直接手选，避免只选整片日本地区而推荐过宽。正文也可插入现有 Spot 卡。关联并不代表作者已到访。
7. 如现有 Guide 确实引用该知识文章，在 Guide 后台的 **Published Longform Notes** 搜索并 Add Note 到相应有序路线。现有 Guide 已会显示该 Note；Note 现在也会显示返回该 Guide 的链接。不要为未发生的日本行程捏造已访问路线。
8. 用现有 Preview 检查视频、图片、表格、H2/H3、FAQ、目录与参考链接。最后更新日期来自最近一次成功保存，代表文章编辑时间；**每条政策/票价/班次的“核对日期”仍需在正文写明**，不能用文章保存时间代替。
9. 发布前核对来源、适用日期和全部相关内容链接，再勾选 Published 并确认“Saved to cloud”/发布结果。已有发布与重验证流程继续负责公开快照、路由、列表及 sitemap。当前本地改动尚未部署，线上后台不会提前拥有这些新增展示能力。

Canonical 自动指向 `/notes/{slug}`；旧 alias 的 canonical 仍指向同一正式 slug，无需填写一个新 Canonical 字段。Note 目前没有独立 SEO Title/Description 覆盖框，使用现有 Title 与 Card Summary 即可；未另外造一套 SEO 系统。

## 可复制的正文骨架

下面是写作占位模板，不能原样发布。本文不提供现行日本政策、价格、时刻表结论，也没有核验占位来源。

```markdown
## 阅读说明

本文为出发前资料整理，尚未亲身实测。适用日期：待核对。

## 适合谁使用

填写适用对象与已核对的使用条件。

### 使用限制

填写有依据的限制，并就近附上来源。

## 方案比较

| 比较项目 | 经核对的内容 | 来源与核对日期 |
| --- | --- | --- |
| 适用范围 | 待填写 | [官方来源名称](https://官方页面) · YYYY-MM-DD |
| 价格 | 待核对；写清币种、票种、人数及有效期 | 待填写 |

## 常见问题

### 这个方案一定适合我吗？

根据路线和使用条件说明，不用“实测最划算”替代证据。

## 参考资料

[运营商或主管机关资料](https://官方页面) · 核对日期：YYYY-MM-DD
```

JR Pass 与列车类型核对对应铁路运营商，东京地铁票核对发售/运营方，日本退税核对主管机关和适用时点。具体政策、票价、附加费、班次信息均应有可打开的官方页面；没有核对到的部分明确标为“待核对”，不以测试模板代替事实。

## 本地复查

运行 `node --experimental-strip-types scripts/review-note-publishing.mjs`，打开 `http://127.0.0.1:3227/notes/test-japan-jr-pass?review=2`。四篇测试 Note 的源数据位于 `tests/fixtures/japan-notes.mjs`，全部 published=false、标题和正文明确标记不可发布，不属于正式 data/ 或公开快照。

脚本仅为公开路由展示，在本机测试传输中临时投影为可读，监听 127.0.0.1、禁用外网服务器请求、阻止所有非 GET/HEAD 请求、清空云端写入凭证，并设置 noindex。测试视频 ID 为占位，CSP 阻止外部播放器，因此这里只验证按需插入 iframe、尺寸和原生链接，不能证明真实日本视频可播放。
